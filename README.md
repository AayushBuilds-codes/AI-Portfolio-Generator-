
# AI Resume to Portfolio Generator

This simple Python application reads your resume from a text file, sends it to the Gemini API with strict prompts to prevent AI hallucination, receives a structured JSON response, and dynamically generates a beautifully formatted HTML portfolio.

## Setup Instructions

1. **Clone the repository** (or download the files).
2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
